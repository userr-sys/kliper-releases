# Kliper

Logiciel de clips pour Windows (replay buffer, comme Medal).

## Télécharger

👉 **[Télécharger Kliper pour Windows](https://github.com/userr-sys/kliper-releases/releases/latest/download/KliperSetup.exe)**

Lance le fichier, clique sur Suivant, et c'est installé. Ensuite Kliper se met à jour tout seul avec le bouton « Mise à jour ».

_Ce dépôt contient seulement l'installateur. Le code de Kliper est privé._
